# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1.

In short: be respectful, assume good faith, and keep disagreements focused on the technical merits. Harassment, personal attacks, and exclusionary behavior aren't welcome here.

To report a concern, open an issue or contact the maintainers directly.
