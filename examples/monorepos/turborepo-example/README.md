# Turborepo example — validation fixture for the future Turborepo `WorkspaceAdapter`

Generated with `npx create-turbo@latest turborepo-example -m npm --no-git` — the stock default Turborepo example, untouched. See [docs/monorepo_architecture.md](../../../docs/monorepo_architecture.md) §7: every future monorepo adapter must be proven against a repository actually generated by that tool's own scaffolding, not a fixture that guesses at the config format.

## What's here

- `turbo.json`, `package.json` (`workspaces: ["apps/*", "packages/*"]`) — real Turborepo config, exactly what `create-turbo` produced.
- `apps/web`, `apps/docs` — two Next.js apps, both depending on `packages/ui`.
- `packages/ui`, `packages/eslint-config`, `packages/typescript-config` — three shared libraries.
- `graph-output.json` — the real output of `npx turbo run build --dry-run=json`, checked in as the snapshot a future adapter's test suite should assert against. The task dependency graph it captured:
  ```
  @repo/eslint-config#build       (no deps)
  @repo/typescript-config#build   (no deps)
  @repo/ui#build                  → eslint-config, typescript-config
  docs#build                      → eslint-config, typescript-config, ui
  web#build                       → eslint-config, typescript-config, ui
  ```
  Those dependency edges came from Turborepo's own task graph (driven by real `package.json` `dependencies`), not written by hand.

## What a real `TurborepoAdapter` should reproduce

Per `docs/monorepo_architecture.md` §4, `TurborepoAdapter.buildGraph()` run against this directory should produce:

```ts
{
  tool: 'turborepo',
  projects: [
    { name: 'web', kind: 'application', path: 'apps/web' },
    { name: 'docs', kind: 'application', path: 'apps/docs' },
    { name: '@repo/ui', kind: 'library', path: 'packages/ui' },
    { name: '@repo/eslint-config', kind: 'library', path: 'packages/eslint-config' },
    { name: '@repo/typescript-config', kind: 'library', path: 'packages/typescript-config' },
  ],
  edges: [
    { from: 'web', to: '@repo/ui', kind: 'depends_on' },
    { from: 'docs', to: '@repo/ui', kind: 'depends_on' },
    { from: '@repo/ui', to: '@repo/eslint-config', kind: 'depends_on' },
    { from: '@repo/ui', to: '@repo/typescript-config', kind: 'depends_on' },
  ],
}
```

`node_modules` is not committed (see `.gitignore`); regenerate it with `npm install` from this directory if you need to re-run `npx turbo` yourself.
